Cinematheque Centre Davao: ERD (MySQL data types)

Same entities and relationships as the original ERD, with MySQL column types. Mermaid can't show spaces in a type, so BIGINT_UNSIGNED means BIGINT UNSIGNED. BOOLEAN is stored as TINYINT(1).

Four relationship lines differ from the original ERD so that they match the written business rules in implementation.md: Movie–Screening is optional on the movie side (rule 2), a Reservation has one or more seats (rule 7), a Payment has one or more proofs (rule 12), and a proof has zero or one reviewer (rule 14). The tables and keys are unchanged.

2026-09-26 revision: attendances.control_number removed; PayMongo fields added to payments. payment_proofs and payment_qr_codes retired.

2026-10-06 revision: cancelled bookings release their seats (reservation_seats.released_at, generated held_seat_id, UNIQUE(screening_id, held_seat_id)); unpaid bookings expire after 15 minutes (reservations.cancellation_reason, cancelled_at); movies.poster_path added; payment_proofs and payment_qr_codes dropped.

2026-10-07 revision: reservation_attendees.pwd_id_no added (optional PWD ID number; pwd_indicator is set when it is filled). Actors, directors and genres no longer have separate admin pages: they are entered on the screening/film form (genres from a fixed list). The tables and relationships are unchanged.

2026-10-11 revision (system revision): new programs and movie_program (Program → Movie → Screening; a film can be in several programs, a screening is in one); movies.status and screenings.status (draft/published); screenings.movie_id and program_id required, plus films_count, partner, agency_type, notes; reservations.status is now awaiting_payment / confirmed / cancelled (auto-approval); reservation_seats gains unit_price, discount_type, amount_due (20% PWD/Senior discount per ticket); reservation_attendees.company_school required; users.role (super_admin/admin); new reports, report_rows and report_events (one Manila report per program, frozen rows, lock and audit trail). Movie–Screening is now mandatory on both sides of the screening.
